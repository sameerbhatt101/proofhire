DeFi, RWA, DePIN, Gaming, AI. Every project must integrate Attestcoin Protocol.

Public page does not publish a full weighted rubric. Core stated criterion: depth of Attestcoin utilization. Need working integration code + technical docs.

## Submission checklist
Project: name, logo optional, sector, description, Attestcoin summary, GitHub+README, deck PDF URL, demo video URL.
Team (each): name, email, optional socials/resume, bio, role, residence, citizenship.
Rules: original hackathon work, testnet deploy, Attestcoin core, IP OK, team size >=1, eligibility OK.
