Problem

Today
  • Freelance / agent payouts settle on platform trust
  • Clients live on Ethereum; credit rails live elsewhere

  • Reputation is off-chain and gameable
Needed
  • Acceptance as a verifiable on-chain fact
  • Capital release only after cryptographic proof
  • Creditcoin reputation from proved work, not scores
  • No centralized settlement operator

Why Attestcoin is core

Integration depth — not a wrapper

In-transaction verify

Payout path calls BlockProver precompile 0xFD2 inside the Creditcoin tx via ASCBase (@gluwa/asc-contracts).

ASCBase dedupe

Query already processed → replay fails. Escrow cannot be double-spent from the same attested source tx.

EvmV1Decoder binding

Receipt status + event checks: emitter allowlist, job/worker binding, receiptStatus == 1.

USC ProofBuilder

Readability worker: wait attestation → ProofBuilder.getProof → vault.execute (@gluwa/usc-sdk).
